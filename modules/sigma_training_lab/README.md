# Training Lab & SLM Forge — Sigma Studio Module

Modulo avanzato per il fine-tuning e la valutazione di Small Language Models (SLM) in **Sigma Studio**.

## Funzionalità
- 🧠 Fine-Tuning QLoRA con Unsloth e PEFT
- 🤖 Autopilota Intelligente per la ricerca autonoma degli iperparametri ottimali
- 🇮🇹 Forgia SLM Italiana con dataset linguistici selezionati
- 📊 Valutazione su 11 benchmark ufficiali (MMLU, GSM8K, HumanEval, ARC, BBH...)
- 📦 Esportazione automatica quantizzata GGUF per Ollama e LM Studio
- 🔧 2 Server MCP dedicati (`Training MCP` e `Benchmark MCP`)

## Installazione
Dall'**Hub Moduli & Estensioni** di Sigma Studio → Installa "Training Lab & SLM Forge"
