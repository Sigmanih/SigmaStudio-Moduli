# Pipelines Lab & Dynamic Swarm — Sigma Studio Module

Modulo di orchestrazione DAG e swarm multi-agente per **Sigma Studio**.

## Funzionalità
- 🚀 Pipeline Predefinita con template pronti e memoria distribuita
- 🧩 Pipeline Designer visuale con grafi aciclici diretti (DAG)
- 🔄 Feedback loop automatico e auto-correzione
- 🤖 Decomposizione automatica di obiettivi complessi
- 📡 Streaming in tempo reale delle sessioni di ricerca
