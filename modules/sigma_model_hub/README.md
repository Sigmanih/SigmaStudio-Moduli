# Model Hub & Hugging Face Downloader — Modulo Sigma Studio

Modulo per la ricerca, il download streaming e l'avvio immediato di modelli da **Hugging Face** (GGUF, Safetensors, MoE, Vision, Audio) direttamente in **`⚡ SigmaEngine`**.

## ✨ Funzionalità
- 🔍 **Esploratore Hugging Face**: Ricerca per categorie (*LLM, MoE, Coding, Vision, Audio, Reasoning*).
- 📥 **Download Manager**: Download asincrono con calcolo velocità (MB/s), percentuale, tempo stimato (ETA) e ripristino/resume.
- ⚡ **Deploy in SigmaEngine**: Calcolo automatico partizionamento VRAM su GPU 0 (RTX 5070 Ti), GPU 1 (RTX 5060) e RAM di sistema.
- 🤖 **Server MCP**: Tool per agenti autonomi per scaricare e attivare modelli al volo.

## 🚀 Installazione
Dall'**Hub Moduli & Estensioni** di Sigma Studio → Installa **"Model Hub & HF Downloader"**.
